# GPi CASE 2 Controls

| Button | Action |
|---|---|
| D-pad | Move in-game |
| A (fleft) | Confirm / Shoot |
| B (fright) | (unused) |
| X (fup) | (unused) |
| Y (fdown) | (unused) |
| Start | Start game / Confirm |
| Select | Escape / Back to menu |

## Installation

```sh
sudo apt install love
```

Then run:

```sh
chmod +x snkrx-gpi.sh
./snkrx-gpi.sh
```

## Display

The GPi CASE 2 has a 480x320 screen (3:2 aspect ratio). The game uses letterbox rendering to maintain its 16:9 (480x270) aspect ratio, adding black bars at the top and bottom.
